---
title: "Tuetut alueet"
---

Kilowahti tukee 43 hinta-aluetta 30 Euroopan maassa *(versiosta 2026.8.0; sitä ennen Tanska, Viro, Suomi, Latvia, Liettua, Norja ja Ruotsi)*:

| Maa | Alueet |
|---|---|
| Alankomaat | `NL` |
| Belgia | `BE` |
| Bulgaria | `BG` |
| Espanja | `ES` |
| Irlanti | `IE-SEM` |
| Italia | `IT-NORD`, `IT-CNOR`, `IT-CSUD`, `IT-SUD`, `IT-CALA`, `IT-SICI`, `IT-SARD` |
| Itävalta | `AT` |
| Kreikka | `GR` |
| Kroatia | `HR` |
| Latvia | `LV` |
| Liettua | `LT` |
| Montenegro | `ME` |
| Norja | `NO1`, `NO2`, `NO3`, `NO4`, `NO5` |
| Pohjois-Makedonia | `MK` |
| Portugali | `PT` |
| Puola | `PL` |
| Ranska | `FR` |
| Romania | `RO` |
| Ruotsi | `SE1`, `SE2`, `SE3`, `SE4` |
| Saksa ja Luxemburg | `DE-LU` |
| Serbia | `RS` |
| Slovakia | `SK` |
| Slovenia | `SI` |
| Suomi | `FI` |
| Sveitsi | `CH` |
| Tanska | `DK1`, `DK2` |
| Tšekki | `CZ` |
| Unkari | `HU` |
| Viro | `EE` |

:::note[Näyttövaluutta euroalueen ulkopuolella]
Euroalueen ulkopuolisilla alueilla hinnat voi näyttää eurojen sijaan paikallisessa valuutassa (SEK, NOK, DKK, CHF, PLN, CZK, HUF, RON, RSD, MKD). Ne muunnetaan euroista päivittäisellä vaihtokurssilla. Katso [Asetukset](/fi/configuration/).
:::
